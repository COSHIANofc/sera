# License policy

CDL v1.0 is officially published (25 November 2026) and is applied to SERA under the owner's instruction. The authoritative Japanese text and unofficial English reference are reproduced unchanged from [CDL-v1.0](https://github.com/COSHIANofc/coshian-licenses/releases/tag/CDL-v1.0), upstream commit [`de28c8bd5238ac76f817980fd9beb8951083f538`](https://github.com/COSHIANofc/coshian-licenses/tree/de28c8bd5238ac76f817980fd9beb8951083f538/CDL/versions/1.0). There was no existing SERA license file to replace. Prior rights, if any, are not revoked. Confirm that all SERA rights holders have authority to apply CDL, and identify the actual project copyright holder before adding a copyright notice. The copyright notice in the license text concerns the license document; branding and official attribution are distinct from ownership.

`LicenseRef-CDL-1.0` is a custom identifier, not an SPDX-listed license; CDL is not OSI-approved. Cargo uses `license-file`. Later versions do not apply automatically. Refer to the complete authoritative text, not this summary.

Third-party libraries, data, maps, responses, fonts and assets retain their own terms. Verify compatibility, permissions, attribution and redistribution before use; public access alone is not permission. Do not invent exceptions. Future binary distributions must supply or identify the exact corresponding CDL-covered source, version or commit, build instructions, scripts and dependency versions, license, attribution and applicable third-party notices as required by CDL. A link to the latest branch alone is insufficient. Review rights and distribution conditions before publication.
