# Repository instructions

SERA is a supplementary earthquake-monitoring TUI in planning. Implement only the phase authorized by the project owner; Phase 0 does not implement monitoring or a TUI. Keep code explicit, small, safe and free of unnecessary dependencies and speculative modules.

Use `main` for stable code, `develop` for integration, and `feature/`, `fix/`, `hotfix/`, `chore/`, or `docs/` branches for work. Preserve existing changes and history. Local commits are allowed when authorized; never push, create PRs, merge remotely, change GitHub settings or publish releases without explicit authorization.

Run the checks in docs/ci.md for applicable changes. Report unrun checks honestly. Update documentation when behavior, design, build or license policy changes. Preserve the exact CDL v1.0 text and third-party terms; never assume a later license version applies. See docs/license-policy.md.

Never fabricate disaster data or represent stale, missing, simulated or predicted information as current observation. Warnings remain visible during navigation; countdown expiry, final reports and disconnection do not mean safety. SERA supplements official information and does not replace it. Verify provider permissions, data rights and regulatory requirements before integration or distribution.
