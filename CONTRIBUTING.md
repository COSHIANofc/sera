# Contributing

Use Rust 1.100.0 with rustfmt and Clippy, preferably via rustup and the checked-in toolchain file. Run the commands in [CI](docs/ci.md). Keep changes focused and describe behavior and tests in the proposed pull request; avoid live provider calls in mandatory tests. Branch from `develop` where available, using `feature/`, `fix/`, `hotfix/`, `chore/` or `docs/`. `main` is the stable branch.

SERA adopts CDL v1.0; read [LICENSE](LICENSE), including its contribution terms, and [license policy](docs/license-policy.md). Only submit work you have rights to contribute, and identify third-party material and its terms. No separate contributor agreement is currently specified.

For potential vulnerabilities, contact the repository owner privately using an available GitHub private security reporting channel if enabled; avoid posting exploit details publicly. No security response service or timeline is promised.
