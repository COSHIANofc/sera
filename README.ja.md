# SERA — 地震情報監視システム

SERA（Seismic Event Radar Application、Develop by COSHIAN）は、日本と周辺海域を対象とするターミナル向け地震情報監視アプリケーションの計画です。Phase 0 は Rust の基盤と CI 設定のみで、実際の監視、警報、地図、TUI は未実装です。対応目標は macOS、Linux、Windows です。

SERAは地震情報を補助的に監視するためのソフトウェアであり、気象庁などが提供する公式の緊急地震速報や防災情報を代替するものではありません。
