# SERA — Seismic Event Radar Application

SERA (地震情報監視システム), Develop by COSHIAN, is a planned terminal-based earthquake monitoring application for Japan and surrounding waters. Phase 0 provides only a Rust foundation and CI configuration; live monitoring, warnings, maps and a TUI are not implemented. The platform targets are macOS, Linux and Windows.

SERA is a supplementary earthquake monitoring tool and must not be used as a replacement for official emergency warnings or disaster prevention information.
